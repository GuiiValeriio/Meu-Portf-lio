Meu Portfólio

Meu primeiro projeto de desenvolvimento web.

V1 - HTML

Nesta versão, desenvolvi a estrutura inicial do meu portfólio utilizando HTML.

O que aprendi

- Estrutura básica de um documento HTML
- Títulos com "h1" e "h2"
- Parágrafos com "p"
- Listas com "ul" e "li"
- Links com "a"
- Links para e-mail utilizando "mailto"

Tecnologias

- HTML

V1 - CSS

Nesta versão, comecei a estilizar o portfólio utilizando CSS, aprendendo como modificar a aparência e o posicionamento dos elementos da página.

O que aprendi

- Conexão entre HTML e CSS utilizando "link"
- Seletores de elementos
- Alteração de cores com "color"
- Alteração da cor de fundo com "background-color"
- Utilização de cores no formato "rgba()"
- Centralização de textos com "text-align"
- Espaçamento externo com "margin"
- Espaçamento interno com "padding"
- Posicionamento dos marcadores de listas com "list-style-position"
- Utilização da propriedade "display"
- Diferença entre "display: block" e "display: inline"
- Organização e alinhamento dos elementos da página

Resultado

A primeira estilização deixou o portfólio com um fundo escuro, textos claros e uma organização mais centralizada, criando a base visual para as próximas versões do projeto.

Tecnologias

- HTML
- CSS
