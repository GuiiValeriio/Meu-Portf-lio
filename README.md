Meu Portfólio

Meu primeiro projeto de desenvolvimento web.

Este projeto foi criado durante meu processo de aprendizado em Análise e Desenvolvimento de Sistemas. A ideia é acompanhar minha evolução na programação através de versões do próprio portfólio.

---

V1 — HTML

Nesta versão, desenvolvi a estrutura inicial do portfólio utilizando HTML.

O que aprendi

- Estrutura básica de um documento HTML
- Títulos com "h1" e "h2"
- Parágrafos com "p"
- Listas com "ul" e "li"
- Links com "a"
- Links para e-mail utilizando "mailto"
- Identificação de elementos utilizando "id"
- Conexão de arquivos externos

Tecnologias

- HTML

---

V1 — CSS

Nesta etapa, comecei a estilizar o portfólio utilizando CSS.

O que aprendi

- Conectar um arquivo CSS ao HTML utilizando "link"
- Seletores de elementos
- Alteração de cores com "color"
- Alteração do fundo com "background-color"
- Utilização de cores no formato "rgba()"
- Centralização com "text-align"
- Espaçamento externo com "margin"
- Espaçamento interno com "padding"
- Posicionamento dos marcadores de listas com "list-style-position"
- Utilização da propriedade "display"
- Diferença entre "display: block" e "display: inline"
- Organização e alinhamento dos elementos

Resultado

A página recebeu sua primeira identidade visual, utilizando um fundo escuro, textos claros e elementos organizados.

Tecnologias

- HTML
- CSS

---

V1 — JavaScript

Nesta etapa, adicionei minha primeira interação utilizando JavaScript.

O que aprendi

- Criar um arquivo JavaScript externo
- Conectar o JavaScript ao HTML utilizando "script"
- Utilizar "id" para identificar elementos
- Utilizar "document.getElementById()"
- Criar uma constante com "const"
- Utilizar "addEventListener()"
- Trabalhar com o evento de clique ("click")
- Criar uma função
- Utilizar "alert()"

Resultado

Foi criado um botão de contato que responde ao clique do usuário através de JavaScript.

Tecnologias

- HTML
- CSS
- JavaScript
